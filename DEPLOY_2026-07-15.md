## What's in this package

### 1. Silent auto-update (v25.529–531) — needs your caching sign-off
Stops users getting stuck on an old version **and** on stale data in a long-open tab.
- New **`GET /api/version`** → `{version, data}`, `Cache-Control: no-store` (`data` = latest change across the
  ETL-fed SOURCE tables: sales_actuals, products, inbound_shipments, flexport_shipments; cached 60s).
- Client poll (in the SUPPLY harness): every 5 min / on focus / 15s after load. Reloads when the **code
  version** changes, the **source data** changes, or the tab has been **open >30 min**. Graceful: reloads
  **silently** when the tab is backgrounded or visible-but-idle ≥90s; otherwise shows a small **Refresh**
  nudge and retries every 30s. User-edited tables (forecasts/POs/deposits) are deliberately EXCLUDED from the
  data signal so a user's own edits never trigger a reload.
- **Supplier portal (v25.532):** same auto-update now runs on `portal.html` too (version + 30-min staleness).
  `/api/version` is now **gate-exempt / public** (returns only version + a data timestamp) so a portal session
  can poll it; the portal page is served `no-store` with the version stamped in.
- Main app HTML is already served `no-store`, so a reload is always fresh — **provided nothing caches it at
  the edge.** Please action the asks in `ADVISORY_2026-07-14_auto-update.md`:
  - confirm `/` (→ `/api/index`) HTML and `/api/version` are **not** edge/CDN-cached on horizon.dockandbay.com;
  - confirm `portal-view.js` is served no-cache/versioned;
  - confirm no service worker / CDN page-rule caching HTML.
  (Serverless responses aren't edge-cached by default, but please verify on the live project + custom domain.)

### 2. FBA tab (v25.527–528)
- New **"AWD · FBA <3wk"** filter (US only): SKUs with AWD on hand > 0 AND FBA cover under 3 weeks (FBA
  on-hand+inbound ÷ avg weekly FBA demand over the next 90 days). Pure filter — no calc changes.
- **FIX:** an FBA-view bug where the pills fell back to the Buy-plan set (a `_CU` reference that only existed

- **Per-country URLs** for the BUY and FBA tabs: `#/buy/us`, `#/fba/uk`, etc. — country pills write the hash,
  and those URLs deep-link straight to that view + market.

  — it is NOT in this package; only the filter above is.
