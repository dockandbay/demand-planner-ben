# PART D — How to work here (verification chain, in order, every change)

1. Edit via a node script with exact-anchor `split()` counts (throw on mismatch; nothing written on failure). Never `sed` big edits; never `node -e` with `$1` or nested heredocs (shell ate a `$1` once → silent SQL error; a heredoc inside `node -e` swallowed a memory write once).
2. Syntax: `new Function()` per `<script>` block for the artifact / inject; `node --check server.mjs`; `new Function(portalView)`.
3. Bump `package.json` version (APP_VERSION derives from it) + prepend `CHANGES.md` entry.
4. Restart sandbox: `pkill -9 -f "node server.mjs"; nohup node server.mjs >> server.log &` (never kill-by-port).
5. `curl -s -o index.html http://localhost:8124/` → `node scripts/dev/render_check.cjs index.html` must say `JS errors: 0` (jsdom; NODE_PATH=repo node_modules).
6. `npm test | grep -q "ALL CHECKS PASSED"` (chain with `&&` so a failure blocks the commit).
7. **Buy-affecting change?** `node scripts/dev/bp_snap.cjs index.html out.json` before AND after (needs `buildLiveDemand()` + `buildLiveBpOverlay()`, done inside); diff `mkts[m].units` and `map[sku]=[buy,urgent]`; explain every delta or revert.
8. Commit with the Claude trailers, `git push origin phase-2.1-suppliers` (gh account `dockandbay`; `gh auth switch --user dockandbay` on a 403). Every version gets its own commit.

# PART E — Gotchas learned this thread (don't relearn)

- `supply/hz-theme.css` rules carry `#app` (two ids) and OUT-RANK the artifact's own phone media rules; a theme rule that forces `display` needs the state class (`.open`) or it kills a toggle (v27.573 Filters bug).
- A trailing `// comment` appended to a one-line function swallows the rest of the line (v27.556 pinned the "/" picker to the page edge until v27.568). Never append comments to lines that continue.
- Portal PO rows come from `GET /api/portal/bootstrap` (server ~15837), not `po-detail`; enrich POs there.
- Per-cell HTTP writes through the pooler cost ~1.6s each: always batch (pattern: `ka-forecast-cells`, earlier `bulk-write-batching` memory).
- `express.json` limit is 25MB; timeline uploads cap at 4MB per file client + server (413).
- `portal_attachments.po` is a polymorphic key (PO ref / `PSAMPLE-<id>` / SR ref / shipment ref); portal GET checks PO, sample-ref and shipment-ref ownership.
- `subcatSkuEffTotals` returns `totals` / `discTotals` per month — the cheap source for a discontinued-unit share.
- Route order: specific `/api/supply/...` routes must be registered BEFORE `app.get('/api/supply/:section')` (barcode-lookup, po-search, barcode-projects).
- `ym()` keys are `YYYY_MM` for sales/forecast maps; Key Accounts uses `YYYY-MM`.
- Ben's phrasing "units to revenue and targets" meant ADD units beside money, not replace (v27.576 → v27.580). When a request could mean either, build the additive reading.
