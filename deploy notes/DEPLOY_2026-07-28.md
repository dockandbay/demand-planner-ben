## ⚠️ Data / n8n dependencies to wire (important)

Two barcode-source changes now read from **`planner.products`** instead of `sku_labels`. For live barcodes to render correctly, these `products` fields must be populated (they come from Airtable `sku_child` via n8n):

1. **Barcode swatch** now reads `products.colour_swatch_url` (fallback `sku_labels.swatch_url`). `sku_labels.swatch_url` is now redundant. → n8n must map Airtable `sku_child.colour_swatch_url → planner.products.colour_swatch_url`.
2. **Barcode printed size** now reads `products.size_long` (was derived from the product name / `sku_labels.size`, which showed e.g. "LANYARD"). → n8n must map Airtable `sku_child.size_long → planner.products.size_long`.

If those mappings aren't in the n8n sync yet, please add them, else new/changed SKUs will show blank swatch / size on barcodes.
