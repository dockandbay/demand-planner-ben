## 3. Server (`server.mjs`) changes — no migration

- **ERP completion-date deviation** (`erp_date_pending`, v25.293): now flags only when the gap ≥ **5% of
  days-until-completion, with a 3-day minimum floor** (was a 10% ratio with no floor, which false-flagged a
  1-day gap on near-term POs). Verified against live-shaped data: 0 POs flagged with a ≤2-day gap. Query only.
- **Cin7 push — voided-order guard** (v25.294): before UPDATE-ing an existing Cin7 PO, `/cin7-lines` now checks
  the mirrored order's `isVoid`/`status`; if it's voided or gone, it drops the stale `erp_po_id` mapping and
  CREATES a fresh PO instead of resurrecting/re-approving the dead one. Affects the live Cin7 write path.

Everything else in this package is front-end (`supply/inject.html`, `artifact_v16.7.html`).

## 4. What changed (all in CHANGES.md, v25.271–293)

**ORDER PLAN**
- "PLAN" buy-plan popup opens from ORDER PLAN + the Create-3PL-PO modal (country tabs in the popup).
- Cell shortcuts: `4c` = 4 cartons, `150r` = round up to nearest carton.
- Fast 120ms tooltips (why a cell is red; what a partial is).
- Carton column moved to col 2 (sticky); filter search also matches colour long; past-discontinue rows tinted red.
- No scroll-jump on cell edit or on approving a partial.
- XLSX export is always **ordered-only** SKUs (ignores the All-SKUs pill).

**PURCHASE ORDERS**
- Expanded PO detail (sub-tabs) stays pinned to the left while the wide grid scrolls (JS transform).
- Assigning a shipment is now **silent** (no full re-render / lost place) and **live-updates the open DATES tab**.
- Grid no longer sticks on "all" after a PO jump — defaults to In progress.
- Shipment drawer: date overrides recompute the chained Ship/Arrival/Completion dates live.
- DATES source always references/links the assigned shipment (even before it has dates).
- ERP date-deviation threshold (see §3).
