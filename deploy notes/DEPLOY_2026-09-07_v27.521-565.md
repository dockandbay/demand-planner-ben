## Server changes (server.mjs)

New routes (all read-only unless stated):
- `GET /api/supply/barcode-lookup?code=` — barcode → SKU card (products + `planner.barcode_projects` overrides). Registered BEFORE the generic `/api/supply/:section` handler (it was shadowed at first; v27.562).
- `GET /api/product/batch-review-list`, `GET /api/product/batch-review/:id` — Sample Batch Review page data (reuses `productSampleList`).
- `POST /api/product/note/upsert-feedback` — rewrites the existing "Feedback on REF_vN · Component:" timeline note (text, tags, Pantone, optional `attachment_id`) instead of adding a new one; inserts only when none exists.
- `GET /api/product/sample/:id/card.pdf` now uses a shared `sampleCardPdf()`; new `GET /api/portal/product-sample/:id/card.pdf` (portalAuth + ownership) serves the same PDF to suppliers.
- `GET /api/portal/product-components/:ref` (portalAuth + ownership) — the components this supplier owns on a product (drives the portal "Aspects sampled" list).
Changed: `/api/product/sample/:id/aspect` accepts component keys `c<id>` and `awc_comment` (mig 266); `createProductSample` / portal `meta` accept component keys; `/api/product/note` accepts `attachment_id`; `/api/product/notes/:ref` returns `attachment_mime`; `productSampleList` returns `awc_comment`, `updated_at/updated_by` per aspect and `feedback_notes`; `/api/supply/suppliers` returns `active`, `/api/supply/supplier/:id` accepts `active`, `/api/supply/lookups` suppliers exclude `active=false` (currency map keeps all).

## What changed (by area)

### DEMAND run-off model (v27.527, 534, 544, 545, 546, 554) — BUY-AFFECTING, approved
One allocator `runoffAlloc(sku, country)` replaces five per-channel copies. Per discontinued SKU: a 3PL pool (3PL + non-GRS + 3PL inbound) shared by DTC / B2B / TIK and by FBA once FBA's own pool (FBA + US AWD + FBA inbound) is gone; pools deplete from the current month (pre-discontinue months included); pro-rata when a month is short; sets can only sell what their discontinued components can still build (set demand competes for the component pool; build-on-fly sets have no own 3PL stock); a stranded tail ≤100 units rolls into the next month. Smoothing: months with no active SKU smooth across run-off SKUs; the Auto sweep no longer runs the legacy `recalcDiscontinued` pass (it wrote per-channel stock-capped zero overrides — the root cause of the phantom FBA zeros).
