## 2. NEW — "recently received POs" feature (n8n + secret + config)
n8n populates a feed table; HORIZON auto-completes the PO, drops a timeline note, and emails the supply planner.

- **n8n job:** upsert rows into `planner.recently_received_pos` (`po`, `received_date`), then **`POST https://<host>/api/supply/received-pos/process`**.
- **Secret (v26.756):** set env **`N8N_WEBHOOK_SECRET`** on live; n8n must send header **`x-webhook-secret: <that value>`**. (If the env var is unset the endpoint is open — fine for sandbox, but **set it on live**.)
- **Email:** needs `RESEND_API_KEY` (already live) **and** a supply-planner address in **CONFIG ▸ Admin ▸ General ▸ Supply planner** (`app_settings.supply_planner_email`). Blank = no email (PO still auto-completes + timeline note).
- Behaviour: not-yet-`COMPLETE` PO → `status='COMPLETE'` + timeline note + email; already-COMPLETE / PO-not-found → no action. Idempotent (`processed_at`). The auto-complete note shows in the ✉ Inbox bell and counts as a PO "Unread timeline note(s)" action.
