## Review before deploy — the one buy-touching change

**v27.637 — Set-aware smoothing (two-totals fix).** Replaces the v27.634 interim guard.
Smoothing a set sub-category (e.g. MIXNMATCH) used to inflate it (50 → 72): the water-fill
targeted the raw box forecast, but set rows explode to box × setSize. Now the water-fill runs
in EXPLODED space (target = the exploded cell) and rounds back to whole boxes with a
never-overshoot largest-remainder pass, so the exploded row-sum == the cell.
- **Default buy is byte-identical** — verified before/after across UK/US/EU/AU/CA. Only a
  *deliberate manual smooth* of a set sub-cat now writes corrected (smaller, un-inflated) box
  overrides. Sub-cats with no sets take the identical box-basis path as before.

Everything else in this package is display / phone-only and does **not** move the buy or forecasts.
