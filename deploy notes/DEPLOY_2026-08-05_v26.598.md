## Themes in this bundle (by area)

### Live-logic fixes (DEMAND / PO / portal)
- **DEMAND plan SKU search FIXED** (v26.566) — was returning an **empty grid** for any SKU on live. Two stacked bugs in `skuMatchQ`: (1) defined inside the `var BP=(…)` IIFE so the DEMAND module threw `ReferenceError` and aborted the whole grid render → fixed with a `window.skuMatchQ` alias; (2) query tokens weren't lowercased → uppercase searches matched nothing → fixed with `String(q).toLowerCase()`. Verified via jsdom render harness.
- **DEMAND plan download FIXED** (v26.568) — same scope class (`buildXlsx is not defined`); added `window.buildXlsx` alias.

Now reads `p.final_invoice`; due total includes the credit; credit line relabelled "Additional credit / charge" and wraps (no clipping).
- **CONFIG ▸ Suppliers** magic-link button label "link" → **"magic link"** (v26.565/567).
