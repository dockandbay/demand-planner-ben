## 3. New runtime settings (app_settings — no migration, safe defaults)

Two new keys the app reads from `planner.app_settings`. **Both default to today's behaviour if absent** — nothing changes on deploy until someone flips them in the UI.

- **`buy_logic`** — `'cover_weeks'` (default) or `'ssm'`. The buy-plan logic switch (see §4). Default = the buy plan is **byte-identical to today**.
- **`ssm_params`** — JSON tuning for SSM (service level by tier, seasonal floor, review cycle, FBA cap). Absent = built-in defaults (A 99 / B 97 / C 93 / seasonal floor 97 / cycle 4wk / FBA cap 8wk).

## 4. New features

**Service-Level Stock Model (SSM)** — a second buy-plan logic, run alongside cover-weeks:
- **DEMAND ▸ Config ▸ Buy plan logic** — the Cover-weeks ↔ SSM toggle + a full explainer + editable parameters (writes `buy_logic` / `ssm_params`). Default OFF.
- When ON, the buy engine sizes each SKU's cover from safety stock (`Z·√(L·σ_d² + d²·σ_L²)` + cycle) instead of flat cover-weeks, with the service level set by `market_tier` (A/B/C) + a seasonal floor. Complex Rules still apply on top. FBA is modelled as China-direct (long lead) capped at 8 weeks; seasonal SKUs pre-buy the whole remaining season at 3PL.
- **DEMAND ▸ Exceptions ▸ Recommendations** — advisory ABC re-tier suggestions (Core scored on annual sales, Seasonal on peak; advisory only, no write-back).
- Uses existing product fields: `market_tier`, `core_seasonal`/`is_core`, `china_to_<mkt>_lead_time_weeks`, `production_lead_time_weeks`, and `planner.inventory_snapshots` (stockout signal) + `po_delivery_history` (lead-time variability). No new tables.

**Navigation restructure** (all deep-link redirects handled; old bookmarks still resolve):
- **CONFIG** is no longer a top-bar tab — it's a **⚙ cog** icon top-right (next to `?`).
- **CONFIG ▸ General** → renamed **Email notifications** and moved under **Admin** (`#/config/admin/email-notifications`).
- **SUPPLY ▸ CONFIG** — new sub-tab hosting the supply-chain settings + Key accounts + Portal + Portal users (flat list, `#/supply/config/<item>`).
- **DEMAND ▸ Config** — new group: Contribution model · Buy plan logic · Discontinued sub-categories (`#/demand/config/<item>`). *(Contribution model + Discontinued sub-cats were lifted to module-scope `window.hzCfg*` fns so they render on the DEMAND surface.)*
- **DEMAND ▸ Analysis** group (Summary · Accuracy · Snapshots · Trends · Safety stock · Ship bags).

**Ship bags** (DEMAND ▸ Analysis ▸ Ship bags): added a SKU forecast table (SHIPBAG-MED/LAR/XLG × market, current vs recommended) with an **Apply** button that writes the recommended monthly qty into those SKUs' DTC forecast override.

**CONFIG ▸ Suggestions** table: Suggestion column widened to 40%, Status columns merged into one field, stakeholders wraps.
