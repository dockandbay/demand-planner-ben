## 3. New runtime settings (planner.app_settings, no migration, safe defaults)

Both default to today's behaviour if absent, so nothing changes on deploy until someone flips them in the UI.

- **`buy_logic`** — `'cover_weeks'` (default) or `'ssm'`. The buy-plan logic switch. Default keeps the buy plan **byte-identical** to today.
- **`ssm_params`** — JSON tuning for SSM (service level by tier, seasonal floor, review cycle, FBA cap). Absent uses built-in defaults (A 99 / B 97 / C 93 / seasonal floor 97 / cycle 4wk / FBA cap 8wk).

## 4. New features (grouped)

**DEMAND analytics (the bulk of this batch):**
- **Trends** (DEMAND ▸ Analysis ▸ Trends): category-trends report with Channel-mix / Multi-year / Plan-sanity / Type-mix panels, country pills, category and group filters, month-range and sub-category drill-down, 10-min cache.
- **Exceptions** (DEMAND ▸ Exceptions): deep-linked L3 sub-tabs (No availability, Available-no-cover, Discontinued-but-active, Selling-no-forecast, Forecast anomalies, Data & config), inline SKU override, current-month = forecast-of-actuals.
- **Accuracy** (DEMAND ▸ Analysis ▸ Accuracy): forecast accuracy and bias vs locked snapshots.
- **Safety stock** (DEMAND ▸ Analysis ▸ Safety stock): service-level safety stock run alongside the current buy plan, with data-driven lead-time variability from `po_delivery_history` and demand unconstraining from `inventory_snapshots`.
- **Service-Level Stock Model (SSM):** a second buy-plan logic behind the `buy_logic` toggle (see section 3). When ON, cover is sized from statistical safety stock (`Z·√(L·σ_d² + d²·σ_L²)` + cycle) with service level set by `market_tier` plus a seasonal floor; Complex Rules still apply on top; seasonal lines pre-buy the remaining season at 3PL; FBA modelled as China-direct, capped at 8 weeks. Plus **Exceptions ▸ Recommendations** (advisory ABC re-tier; advisory only, no write-back).
- **Cell highlights** (DEMAND plan Display Settings ▸ Highlight): baby-blue attention shades (forecast<actual, no-forecast-but-stock), a **Forecast-vs-actual** shade (past 4 completed months), and a **Growth-on-last-year** shade (completed actual months only; cells with zero last year are not shaded). The two coloured highlights are mutually exclusive and toggle instantly.
- **Ship bags** (DEMAND ▸ Analysis ▸ Ship bags): packaging forecast (units to orders) plus a SKU forecast table (SHIPBAG-MED/LAR/XLG per market, current vs recommended) with an **Apply** button that writes the recommended monthly qty into those SKUs' DTC forecast override.

**SETS (v27.002 to 010):** P2 component explosion (build-on-fly set demand explodes into component buys; buy-CHANGING, gated on migs 229/230), P3 contribution model (CONFIG ▸ Demand) plus forecast wiring, demand-plan UI, MASTER/SET group-header labels.

**Prepack map (v27.040 to 046, mig 233):** PP- prepack to SET mapping; prepack on-hand offsets mapped SET demand (carried forward); shortfall explodes to the set BOM; PP- hidden from demand lines and buy; a "PP" rail badge on the demand plan; per-month draw-down and sell-through stop.

**Run-off (discontinued) sub-categories (v27.020 to 022):** plan display for discontinued sub-cats, a Hide-totally config, and stock-capped targets.

**Top-bar Favourites (v27.013, mig 231):** per-user favourite links.

**Navigation restructure (v27.073 to 081; all deep-link redirects handled, old bookmarks still resolve):**
- **CONFIG** is no longer a top-bar tab; it is a **⚙ cog** icon top-right next to `?`.
- **CONFIG ▸ General** renamed **Email notifications**, moved under **Admin** (`#/config/admin/email-notifications`).
- **SUPPLY ▸ CONFIG:** new sub-tab hosting the supply-chain settings plus Key accounts, Portal, Portal users (flat list, `#/supply/config/<item>`).
- **DEMAND ▸ Config:** Contribution model, Buy plan logic, Discontinued sub-categories (`#/demand/config/<item>`).
- **DEMAND ▸ Analysis:** Summary, Accuracy, Snapshots, Trends, Safety stock, Ship bags.

**Smaller items:** DTC-mismatch UX (v27.012), 3PL invoicing fixes (pdfjs worker bundled for the Geneva PDF; Cin7 import summary scoped per-3PL, v27.011), Scenario nav fix and code cleanup (v27.018), Samples detail dev badge / product link / find-past-address (v27.002), CONFIG ▸ Suggestions table (40% Suggestion column, merged Status field, wrapping stakeholders).

## 5. Removed features / endpoints

- **Inventory-snapshot uploader** (was a temporary CONFIG ▸ Admin loader): the page and `POST /api/config/inventory-snapshot-load` are gone. Snapshots now come from CSV/SQL and the n8n flow. The table and safety-stock plumbing stay.
- **Sell-through targets / Set targets** (was DEMAND ▸ Inputs): page plus `GET`/`POST /api/targets` removed; table dropped (migration 234). Two knock-ons: the **Auto-Forecast** report now always uses the default cover-weeks, and **Demand Actions** shows sell-through % without a "vs target" comparison.

## 6. Behaviour changes to be aware of

- With `buy_logic='cover_weeks'` (default): **no change** to buys.
- **CA is decommissioned:** `_INV_BRANCH_MAP` excludes all CA branches; `ca_*` warehouses are dropped from inventory snapshots.
- Current-month cells in the demand plan now show forecast-of-actuals; Exceptions and the highlights build on that.
