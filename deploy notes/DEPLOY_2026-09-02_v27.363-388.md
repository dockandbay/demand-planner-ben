## What changed (by area)

### Sets % — forecast + buy (v27.374 / 375 / 381)  ·  gated on seed 251
- **Sets % wired into the forecast cascade** (v27.374): `buildSkuShares` reserves Sets%/100 of a sub-category for the SET pool, the rest for masters.
- **Buy explosion uses item-equivalent volume** (v27.375): a SET's forecast (item-equiv) is ÷ set size → boxes before exploding into components, so a size-N set no longer over-explodes N×.
- **Reservation goes to ACTIVE sets only** (v27.381): discontinued (build-on-fly, no-stock) sets no longer take a slice of the reservation and strand it; if a sub-cat has no active set the pool collapses to the masters.
- **Net effect on live:** only where a Sets % is configured (i.e. after seed 251, or manual entry). Sub-cats with no Sets % are byte-identical. Expect the buy to move on towel sub-cats once 251 is in.

### DTC mismatch report — overhaul (v27.377–380)  ·  needs mig 254
- Reconciliation rewritten to a **connected-component (many-to-many) grouping**: a PO can serve several SOs and vice-versa; grouped SO-vs-PO SKU/qty. Parses **packed Cin7 `sales_order_ref`** (comma / "and" / slash / trailing spaces) — fixes POs that were falsely shown unmapped.
- **In-app PO↔SO mapping** (`/api/supply/dtc/map` + `/unmap`, table 254): Map PO / Map SO pickers, "app" badge, unmap/suppress. **Never writes to Cin7.**
- **Grouped SOs pill**, PO/SO **search filter**, expandable discrepancy, shows no-PO SKUs, silent refresh on map/unmap.

### PO details PDF — SUG-0034 (v27.383–388)  ·  no migration
