## ⭐ The one to note first — LIVE fix (v27.247)

**BI ▸ Metrics "loading actions" spun forever on live.** Root cause: `computeOpenActions()` (server.mjs) ran ~a dozen heavy COUNT/CTE queries **sequentially** (20-30s on the live pooler) — a cold serverless instance could exceed the function timeout, so the request never returned. Now all those independent metrics run **in parallel** (`Promise.all`) → wall-time ≈ the slowest single query. Same queries, same numbers. No connection is held across an `await`, so excess just queues on the pool (no deadlock). Client also got a **45s abort timeout + Retry** on the board fetch so it degrades gracefully instead of hanging. **Please verify on live** (sandbox's fast pooler masks it).
