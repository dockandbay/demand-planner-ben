## 3. Notable server (`server.mjs`) behaviour changes — no migration, but worth knowing

- **Cin7 per-PO line push (price + qty)** — endpoints `/api/supply/po/:po/cin7-lines` (write, full override),
  `/cin7-verify` (read-only audit), `/cin7-date(s)`. Root-cause fix: send the PO line **`unitPrice = planUSD`**
  (Cin7 converts to base currency); read-back audit uses `USD = unitPrice × currencyRate`. **These write to
  LIVE Cin7** — gate/monitor accordingly.
- **ERP completion-date deviation** (`erp_date_pending`) rethreshold: now flags only when the gap ≥ **5% of
  days-until-completion, min 3 days** (was 10% ratio, no floor → 1-day false flags). Query-only change.
- **`v_product_availability`** reads (pairs with mig 094) — pre-launch SKUs included.
- **Manufacturing** endpoints (`manufacturingData` / `manufacturingActions`) — pair with migs 096/097.
- **SKUs query** now returns `size_long`, `carton_qty`, `colour_long` (pairs with mig 095) — used by ORDER PLAN.

## 4. Ongoing data dependencies (n8n / Airtable → Supabase)

The seeds above are **one-off**. For values to stay current, the n8n sync must map (alongside existing product
fields): Airtable `sku_child.size_long` → `products.size_long`; the Manufacturing BOM; and `product_inventory`
(SOH). Otherwise new/changed products leave these null.
