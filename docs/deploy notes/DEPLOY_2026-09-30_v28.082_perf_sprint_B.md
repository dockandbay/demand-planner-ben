# v28.082 — Performance Sprint B: static shell split (30-Sep-2026)

Follows v28.081 (Sprint A). Server only (`server.mjs`), **no migration, no env var, no client file change,
no product-logic change**. Same code runs in the browser, in the same order, with the same data.

## What changed

Until now `GET /` shipped one 5.6 to 9 MB HTML with the artefact's and inject.html's script inline and the live
data spliced into `var X = {...}` declarations, all `Cache-Control: no-store`. Every visit re-downloaded and
re-parsed ~4.5 MB of unchanged JavaScript.

Now `shellBundle()` prepares once per process (in DEV again whenever either file changes):
- every injected global reads `window.__HZ_G.NAME` when the shell provides it, else its own baked literal
  (`rewriteGlobal`, same locator `replaceGlobal` used, so the same declaration is targeted);
- the scalar hooks (`LAZY_SKU`, `EXTRACT_TS`, `BUY_LOGIC`, `AF_GBP` / `CF_GBP`) read `__HZ_G` the same way;
- version-fixed text edits (VERSION, theme link, `/api/ai` proxy, model swap, PLAN→DEMAND, `__APP_VERSION__`) baked;
- each inline `<script>` body is moved to `/static/<name>.<sha1-12>.js`, gzip pre-computed, served
  `Cache-Control: private, max-age=31536000, immutable`.

`GET /` serves the ~240 KB skeleton (markup + CSS) plus one inline `window.__HZ_G = {...}` data script (in `<head>`,
before the first body script), then LANDING / FBA_DIMS / FIT inline as before. All the conditional injection logic
(allSettled fallbacks, `?lazysku`, try/catch defaults) is unchanged, just writing to `G` instead of the HTML. The
H2 hardening (`</script>` / U+2028 / U+2029 escaping) is applied to the data script.

## Routes

- `GET /static/:name` — content-hashed script files from memory (previous build kept for open DEV tabs). Behind
  the same login as `/` (private cache); no gate exemption needed, the browser sends the cookie for same-origin
  scripts.
- `GET /` unchanged contract (`no-store`, per-user landing, `?lazysku=0` opt-out).

## Prod notes (Diviyaj)

- Nothing to apply beyond the pull. On Vercel the bundle builds on the first request per instance (deterministic
  hashes, so any instance can serve any file). If the edge/CDN strips `Content-Encoding`, the route also serves
  the identity body.
- If a login gate redirects unauthenticated `/static/*` to HTML, nothing breaks: an unauthenticated `/` redirects too.
