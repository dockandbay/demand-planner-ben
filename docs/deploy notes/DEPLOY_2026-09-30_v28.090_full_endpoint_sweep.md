# v28.090 — Full endpoint sweep, round 2 caching (30-Sep-2026)

Perf (Ben: "full review sweep of every endpoint loaded from every menu link L1/L2/L3"). `server.mjs` only, **no
migration, no env var, no product-logic change**.

## Method

Timed all 207 param-free menu-loaded GET endpoints against a fresh server (cold vs warm). Cached the slow,
param-free, user-independent ones. Verified each candidate's `req.query` / `req.me` usage first — the CLIENT
`config` / `commission/*` reads use `req.me.email` (per-user) so were **deliberately left uncached**.

## Left uncached on purpose

- CLIENT `config` / `commission/groups` — per-user (`req.me.email`).
- Search endpoints (`product/sku-search`, `scenario/fx`, `hz-search`) — inputs vary every keystroke.
- Market-param'd analytics (`scenario/auto-forecast`, `scenario/otb`, `kpi/in-stock`) — would need per-param
  keying; the no-param default isn't the hit path. Candidates for a later per-param cache if they bite.
- Live-Xero `xero/status` / `xero/bills` — kept live (connection status must be current; bills vary by since/limit).
- The ~0.4s single-query endpoints — that's the pooler round-trip; not worth caching.
