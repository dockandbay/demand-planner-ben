# v28.094 — Xero bills cache + reconciliation fixes (30-Sep-2026)

Ben. **Migration 317** (`planner.xero_bills`). Server + client. Bundles several related Xero/Flexport fixes.

## 1. Local Xero-bills cache + incremental sync (the big one)

The resolver used to sweep ALL ACCPAY bills live (60 pages × 2 orgs, ~3 min) and the Exceptions view re-fetched every
linked bill by id (~22 s) — a full Xero call every time. Now:
- `planner.xero_bills` caches every ACCPAY bill (id, ref, number, contact, total, paid, due, currency, status, dates).
- `syncXeroBills()` pulls only bills **modified since the last watermark** via Xero `If-Modified-Since` (per-region
  watermark in `app_settings.xero_bills_sync_<region>`). First run = full pull (sandbox: 9,908 bills in ~2:45,
  batched inserts). A **payment/credit-note applied to a bill bumps its UpdatedDateUTC**, so it's picked up next sync.
- Cron `POST /api/cron/xero-bills-sync` + admin `POST /api/supply/xero/bills-sync?full=1`.
- The **resolver** and **Exceptions** now read from the table — reconciliation is a fast local DB read (~50 ms), no
  live Xero per run.

## 2. Resolver correctness (Ben's rule)

- A Xero bill links to a PO only when its Reference/Number **STARTS WITH** the PO (`PO-53EUWK1 / EXDH-…`), never when
  it merely contains it. Fixes Flexport freight bills (`FLEX-… / PO-53EUWK1 …`, raised to the Flexport contact) being
  mis-linked. Applied in the bulk resolver and the per-PO "find links". Validated: PO-53EUWK1 → correct $5,697.72 bill.
- **Incremental resolve** by default: only POs without an existing link are matched (was re-writing all ~769 every
  run). `?full=1` = one-time cleanup (clears stale AUTO xero links to purge the old wrong ones + re-matches all).
  Real discrepancies still surface via Exceptions, which compares every linked PO.

## 3. Exceptions de-noising

- **Non-USD bills are no longer flagged as amount mismatches** (HORIZON is USD; GBP/AUD/CAD/EUR can't be compared raw
  without an FX rate). The due-date check still applies. Removes the biggest false-positive class (sandbox: 263 of 345
  UK bills are non-USD).

## 4. Exceptions UI

- Every row now has **open PO ↗** (opens the PO drawer on the Payments tab, in place) + **open in Xero ↗** (the bill)
  + the type-specific action (Credit note / Find links).

## 5. Flexport booking preview speed

- The preview did a slow inline Flexport bookings harvest (~30 s) whenever the registry was empty, and re-harvested on
  every preview if nothing matched. Now the harvest runs in the **background** (single-flight, 24 h TTL) and never
  blocks — the preview returns instantly with whatever's cached.
