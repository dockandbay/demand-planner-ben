## Server changes (server.mjs)

- **New `POST /api/supply/ka-forecast-cells`** `{client, warehouse, cells:[{sku, month:'YYYY-MM', quantity}]}` — one transaction: set-based delete of the addressed months + multi-row insert (blank/0 = clear), max 5,000 cells per call. Replaces one-request-per-cell for imports and clears (the per-cell route stays for inline edits). On the sandbox a 45 SKU × 18 month file went from ~20 minutes to ~2.5 seconds.
- **Render injection `ASP_ADJ`** from `app_settings.asp_adjust` (JSON, `{"UK|DTC":{"red":9,"disc":10}}`), alongside the existing smoothing settings. Saved through the existing `POST /api/app-settings`.
