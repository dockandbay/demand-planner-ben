# v28.101 — Client price tiers (computed) + preview (30-Sep-2026)

Ben. **Migration 319** (`clients.price_tier`, `price_method`). Server + client. The live line sheet is **not yet

## Model (confirmed with Ben)

- **RT** = market retail (`planner.products <mkt>_rt`, incl tax)
- **ex-tax** = RT ÷ (UK/EU 1.2, AU 1.1, US/CA 1.0)
- **WS** (wholesale) = ex-tax ÷ 2
- **Distributor** = WS × (1 − discount), discount from `planner.distributor_offers` per market + method
  (FOB = Shanghai pickup, EXW = we ship, 3PL = order our stock)

Verified numbers (SKU ACTIVE-SML-ORANGE): AU RT 30 → WS 13.64 → FOB 7.64 · US RT 25 → WS 12.5 → FOB 7.5 / EXW 8.75 ·
EU RT 18 → WS 7.5 → FOB 4.5 / EXW 5.25 / 3PL 6.38 · UK WS 7.5 (no distributor discount configured).

## What's in

- `cpTierPrice(product, market, tier, method)` + `cpDistOffers()` (5-min cache).
- `GET /api/client/price-preview?client_id=|market=` — read-only, returns RT/WS/FOB/EXW/3PL for up to 30 SKUs.
- Client card: **currency is a dropdown**; a **Price tier** row (`{market} RT` / `WS` / `Distributor` + FOB/EXW/3PL
  method, shown only for Distributor) with a **"preview prices ↗"** link that shows the computed table inline.
  Saved via the auto-save (`price_tier`, `price_method` added to `CP_CLIENT_FIELDS`).
