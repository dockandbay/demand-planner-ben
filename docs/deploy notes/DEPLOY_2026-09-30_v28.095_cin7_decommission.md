# v28.095 — Cin7 decommissioned for PO ERP (30-Sep-2026)

Ben: Cin7 is retired; Fulfil is the only ERP for POs. `supply/inject.html` only.

## Changes

- **`erpUploadInert` always targets Fulfil.** The old default was `erp='cin7'`, which is why the "⬆ Update ERP" drift
  button (e.g. on PO-58EUXR1) was pushing to Cin7. Every push now forces `?erp=fulfil`. The date-drift button shows
  whenever Fulfil grid-status shows a requested-delivery drift (not just when the badge passed `fup`).
- **Order Plan sub-tab:** removed the "⬆ Push to Cin7 (full)" button and the "not required in Cin7" tickbox. Kept
  "⬆ Push to Fulfil (full)".
- **PO grid Import/Export bar:** removed the "📅 Sync Cin7 Dates" button (kept "📅 Sync Fulfil Dates"); guarded the
  now-absent button's handler so the grid render never throws.

The orphaned Cin7 handlers (`.op-cin7-full`, `.op-cin7-nr`) are inert (their elements no longer render) and even if
reached would route to Fulfil, since `erpUploadInert` ignores the `erp` argument now.

## Not touched (still Cin7, but not PO-ERP)

The Cin7 *sales-order / DTC import* paths (`tpl/cin7-import`, `dtc/mismatch`) are a separate historical data feed, not
the PO ERP — left as-is. The `erp_date_pending` (Cin7 date-drift) signal on PO rows is now unused by any button; a
later cleanup can drop it from `PO_ROWS_SQL` once confirmed nothing else reads it.
