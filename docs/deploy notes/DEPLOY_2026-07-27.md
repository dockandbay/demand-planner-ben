## 3. What's shipping (v26.108 → v26.212), by area

- **PO self-shipment (new).** A PO can be its own shipment via a MODE gate (sea/air/fob) on PO ▸ SHIPMENTS — full shipment fields inline (carrier, tracking + dynamic link, dates with override→final calc, freight), convert-to-master (+ field binding), coloured sea/air/fob grid badges, carrier tracking badge on the grid. Manufacturing = FOB, never pushed to Cin7 and shows no ERP state. Empty shipments (incl. orphaned self-shipments) are hidden from the grid (search still finds them) and auto-pruned on reassignment; never shown on the portal. Freight/duty/landed/Cash-Flow are calc-identical to a normal master (verified).
- **PRODUCT module** (backed by migs 148–155): size × component approval matrix, samples rework (aspects, sizes, lifecycle status, shipment assignment), Documents tab (uploader + timestamp, D&B vs supplier split), size→SKU mapping, timeline with downloadable file links, RANGE PLAN tab, DASHBOARD approval matrix (desktop table / mobile cards), progressive detail load, reference rename, season grid⇄detail binding.
- **SUPPLY ▸ Reports:** new SUPPLIER DELAYS report (production timing + completion-date movements) with PROD# / started-within-N-months filters.
- **Cash Flow:** Starting Deposits + Deposits Summary reports, merged CSV/Email Export dropdown, moved under PAYMENTS.
- **Timeline:** product timeline matches the PO timeline UI; dd-mmm-yy dates across both.
- **Portal:** Inbox/Recent moved to the top bar, Sign-out removed; sample aspects/sizes/status; shareable deep-link URLs; silent status/shipment updates.
- **Mobile/UX fixes:** DEMAND filter-pill flash removed on non-demand loads; duplicate HORIZON version badge removed on mobile.
