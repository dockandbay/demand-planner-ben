supplier `memberId`; fixed update→sales-order bug (re-asserts company/branchId/isApproved:false); keeps

and imports supplier/branch/SKUs/qty/currency/delivery date; overwrites if it exists; **mirrors the ERP
lines so an imported PO reads as in-sync** (no phantom drift).

**Portal** (v25.327–339): shipment-plan populated for real suppliers; notification badges
(Samples/Shipment/POs); deposits fix + 2dp; samples card left-align/bigger; TIMELINE completion date +
revised production statuses; past-date-in-production conflict flag.

**Mobile PO tab** (v25.353–360): Import/Export pop-down; hide count/ERP-match line; filters 2-per-row
