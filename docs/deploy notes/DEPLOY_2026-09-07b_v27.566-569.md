## Server changes (server.mjs)

- `insertProductSamplePhoto` (used by `POST /api/product/sample/:id/photo` and the portal upload) stores an optional `aspect` (sampled component key, trimmed to 80 chars) in `planner.portal_attachments.aspect` (mig 267).
- `productSampleList` returns `aspect` on each entry of `photos` (null for older / portal uploads).
- `POST /api/supply/sample/:id/received` with `received:true` now also sets `sample_requests.status='COMPLETED'` unless the status is CANCELLED. `received:false` clears `received_at` only and leaves status alone. (Ben's rule: marking a sample shipment received completes it.)
- `GET /api/product/batch-review/:id` items carry `product_type` (from `product_dev_items.type`) for the new filter box.
