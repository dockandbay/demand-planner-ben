## Apply checklist

1. **Run migrations 111 -> 116** on live `planner` (in order). All additive except **114 (drops tables)**.
2. **114 is destructive** -- it DROPs unused/legacy tables + dated `*_bak_*` snapshots. Run it ONLY once you
   are satisfied the backup snapshots aren't needed for rollback. All `DROP ... IF EXISTS` (safe to re-run).
   NOTE (already flagged in the file): it deliberately does NOT drop `planner.product_inventory` -- n8n still
   WRITES to it; retire that n8n step first, then drop it separately.
3. **One-off data backfill (final costs):** so D&B-entered final costs set BEFORE this deploy take effect in
   the ERP push / Cin7 verify / value calcs:
   `UPDATE planner.portal_line_costs SET confirmed_at=now() WHERE final_cost IS NOT NULL AND confirmed_at IS NULL;`
   (From v25.482: `po-line-final` now stamps `confirmed_at`; only pre-existing rows need this one-off.)
4. **No new npm dependencies** and **no new required env vars** this range (`exceljs` + the invoice template
   already shipped with v25.397). `npm install` still fine to run.
5. **Env cautions (unchanged, restating):** do NOT set `DEV_USER` on prod (attribution uses the forwarded auth
   header). `LIVE_DATABASE_URL` is a **sandbox-only** `.env` var (used for the local reseed) -- not for prod.
