## What's in this package (grouped; see CHANGES.md for per-version detail)

**Fixes that specifically NEED this deploy to take effect on live**
- **v25.512** -- the portal PO query never selected `production_status`, so the portal production-status
  dropdown always showed blank regardless of the DB value. Now returned. (This is the "production status is
  blank on the supplier portal" issue.)
- **v25.509** -- `/api/portal/submit` now actually applies `production_status` (was silently ignored on the
  live portal). Also: a MASTER PO marked 'shipped' now advances its shipment to Shipping (master POs only).
- **v25.516** -- buy-plan PO creation now resolves & sets `supplier_id` (was name-only -> no supplier lead
  time -> no computable ETA -> the inbound didn't appear in the buy plan; e.g. PO-57UKLX5's 752 units).

**Buy plan / FBA**
- FBA "Transfer FBA (non GRS)" is now demand-driven (was: push ALL non-GRS stock), carton-rounded-up, with a
  send-all-above-65%-of-pool rule. SOH FBA / SOH AWD columns highlighted light yellow.
- Buy-plan -> PO modal: optional **Batch number** (stamped on created POs). Branch still auto-defaults by
  destination x channel (UK 3PL -> UK ILG, UK FBA -> UK FBA, etc.).
- PO grid Batch/PROD# cell picker sorts descending (newest first).

**Deposits register**
- New editable **Country** column (the region field that drives PO<->deposit matching; AU is isolated).
- **PROD#** is now a searchable picker over ACTIVE productions (CONFIG > Productions / `prod_numbers`).
- Date inputs fill their column + left-align; close-with-remaining uses a Cancel / Yes-close dialog; the
  Close button is hidden while editing; a freshly created blank **+Deposit** shows under the Remaining-open
  filter.

**Portal users / samples / nav**
- Magic-link button copies silently (no double popup).
- Samples timeline shows the supplier name + portal user email (not just "Supplier").
- SUPPLY top tab from CONFIG now lands on PURCHASE ORDERS instead of a blank page.
