## 2. Login-gate exemptions (mirror in the prod gate hotfix)

These paths must bypass the prod login gate because they carry their own auth. All are already exempt in `server.mjs` (around line 889); mirror them in prod:

- `/api/export/csv/*` : Google Sheets exports (checked by `x-export-token`)
- `/client` and `/client-view.js` : client portal page and its JS (magic-link cookie `csid`)
- `/api/cp/*` : client portal API (cookie `csid`)
- `/api/cron/client-sales` : client sales import cron (checked by `x-webhook-secret`)

`/api/assistant/*` and `/api/forecast/replacements` are ordinary `/api` routes. They pass the gate on the existing `pk` cookie, so no exemption is needed.

## 3. Environment variables

- **`ANTHROPIC_API_KEY`**: required for Ask Claude and the existing AI insights. It must be a key with a **credit balance** on the Anthropic account. (Sandbox hit "credit balance too low" during testing; that is billing, not code.)
- **`ANTHROPIC_WORKSPACE_ID`**: optional. Set it only if the key above is org-scoped. Org keys are rejected with "not scoped to a workspace" unless this is supplied. A normal workspace-scoped key needs nothing here.

No other new env vars.
