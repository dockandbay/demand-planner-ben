## 3. New runtime settings (`planner.app_settings`, no migration, safe defaults — default = today's behaviour)

- **`buy_logic`** (already existed) — legacy global switch; retained for back-compat.
- **`ssm_enabled`** (JSON `{"CO|POOL":true}`) — per market×pool SSM opt-in. Absent/`{}` ⇒ **all markets on weeks-cover — buy plan byte-identical.** Legacy `buy_logic='ssm'` maps to all-on.
- **`ssm_params`** — extended with a **`byMkt`** sub-object (`{"CO|POOL":{sl,seasonalFloor,cycleWk,fbaCapWk,seasonMaxWk}}`) for per-market×pool overrides over the global defaults.
- **`ssm_backtest_cfg`** (JSON) — Backtest recommender config: risk service levels (`slLow/slMed/slHigh`), CV thresholds (`cvMed/cvHi`), recency `halfLifeMo`.

All are set from the UI at **DEMAND ▸ Buy Plan** (POST `/api/app-settings`). No action needed on deploy.

## 4. New API routes (server.mjs, existing tables)

- **`POST /api/demand/inventory-upload`** — parses an uploaded Cin7 "Historic & Current Stock Valuations" export (Branch/Category/Code/SOH) + a snapshot date, maps branch→warehouse via the existing `_INV_BRANCH_MAP`, upserts into `planner.inventory_snapshots` (`source='cin7_upload'`), on `(sku,warehouse,snapshot_date)`.
- **`GET /api/demand/ssm-backtest`** — per market×pool historical cover vs demand + service-level risk options; params `from`/`to` (window), `target`. Read-only.
