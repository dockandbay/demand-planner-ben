## ⚠ New cloud cron — Resolve PO links (v28.059)
Schedule **`POST /api/cron/resolve-po-links`** every ~4–6 hours (same `x-webhook-secret` gate,
fails closed). It sweeps Xero ACCPAY bills per org + local Fulfil/Flexport/DHL joins and upserts
`planner.po_links` for the whole PO book, so Linked Records + the Xero payments **Exceptions**
(reconciliation, replaces Xero Compare) stay populated without a per-PO live call. Manual trigger:
"⟳ resolve all links" on PAYMENTS ▸ Xero payments ▸ Exceptions.

## ⚠ New cloud cron — Flexport import every 4 hours
Schedule **`POST /api/cron/flexport-import`** every 4 hours (Vercel cron or n8n).
- Auth: header **`x-webhook-secret: <N8N_WEBHOOK_SECRET>`** (same secret as the other
  crons). Route fails closed (401) without a matching secret.
- It paginates the Flexport `/shipments` API and upserts `flexport_api_shipments`
  (estimated/actual departure + arrival, cargo-ready, mode/status), then records
  `app_settings.flexport_last_sync` (surfaced in the UI as "last sync: dd-mmm-yy hh:mm"
  on PURCHASE ORDERS ▸ Flexport).
- Manual trigger for ops: the "⟳ Import from Flexport" button on that page (admin).
