## 6. Gotchas learned this session
- **Release gate:** `npm run ai-logic:check` must be 0 STALE before every commit. Chain it in the command; v28.379 slipped once and needed a follow-up.
- **zsh globs:** an unmatched glob in `git add` aborts the chain. Add explicit paths only.
- **Sandbox Xero = the LIVE Xero companies.** Never auto-post from the sandbox (group shares auto-apply is production only).
- **Fulfil env:** the sandbox Fulfil env is a setting (`app_settings fulfil_env`). Flip it to `live` only for read-only tests and flip it back.
- **Live DB:** `LIVE_DATABASE_URL` is a restricted read-only user that cannot read some tables (e.g. commission). Use Supabase MCP `execute_sql` for live reads and approved writes.
- **Large live loads:** the Supabase SQL editor rejects large queries. About 0.7 MB per file works (the 8 parts).
- **Prod import mapping differs from ours (PO363).** Check prod behaviour, not just our code.
