## Themes in this bundle (by area)

### Live-logic fixes (DEMAND / PO / portal)
- **DEMAND plan SKU search FIXED** (v26.566) — was returning an **empty grid** for any SKU on live. Two stacked bugs in `skuMatchQ`: (1) defined inside the `var BP=(…)` IIFE so the DEMAND module threw `ReferenceError` and aborted the whole grid render → fixed with a `window.skuMatchQ` alias; (2) query tokens weren't lowercased → uppercase searches matched nothing → fixed with `String(q).toLowerCase()`. Verified via jsdom render harness.
- **DEMAND plan download FIXED** (v26.568) — same scope class (`buildXlsx is not defined`); added `window.buildXlsx` alias.
- **Supplier portal amount-due wrongly $0** (v26.569) — portal SQL aliases `supplier_invoice_total AS final_invoice` but `portal-view.js` read the pre-alias name (undefined). Now reads `p.final_invoice`; due total includes the credit; credit line relabelled "Additional credit / charge" and wraps (no clipping).
- **CONFIG ▸ Suppliers** magic-link button label "link" → **"magic link"** (v26.565/567).
- **PRODUCT detail crash FIXED** (v26.570) — `Cannot set properties of null (onclick)`: `#pm-addsz`/`#pm-del`/`#pm-swatch` were wired unconditionally but only render in one mode; added `if(el)` guards.
- **PO ▸ Client/FBA** — "Custom order product(s)" picker only shows when **Direct-to-Client type = Custom** is ticked (v26.571).
- **PRODUCT Size tab** — fixed clipped component labels (col 1), darker-grey SIZE header rows, **white** component rows (v26.572/573).
- **PO drawer PAYMENTS table — mobile horizontal scroll** (v26.591) — the PO-grid ▸ PAYMENTS sub-tab payment-plan table overflowed the panel on mobile instead of scrolling sideways. `pay-tbl` was on the `.tw` scroll wrapper (so `width:max-content` grew the container past the viewport); moved it onto the inner `<table>` to match the 4 PAYMENTS report tables. CSS/markup only — no desktop change, no data impact.

- **Pre-shipment docs action now flags 1 week BEFORE production end** (v26.575) — `today + 7d` window on the action condition, detail line, and shipments banner.
- **Direct-to-Client supplier approval gated on "Require supplier confirmation"** (v26.576) — aligns to CONFIG ▸ Productions; DtC approval only requested when `require_confirmation` is on, else shows "Not required".

Also **fixed "Payment invalid — amount set with no date" false positives** (e.g. PO-1672805): the check wrongly required the *optional* `final_payment_due` override; that branch was dropped (client + server).
- **Order Plan exception approve is now instant** (v26.578) — optimistic `_poRiskPost` updates the UI immediately from cache and reconciles in the background (was slow round-tripping the whole order plan).
