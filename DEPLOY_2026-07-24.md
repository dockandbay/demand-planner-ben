## 2. Files changed (all in this repo)
- **`server.mjs`** (harness — Diviyaj's area, review): new endpoints for the above (suggestions, product module,
  product/sample-shipments, DtC shipment details, forwarder, branch/shipment delivery notes, additional-cost
  review + approve, document approval, 3PL-invoice report, landing page). **Perf:** shared `PO_ROWS_SQL` const +
  new `GET /api/supply/po-row/:po`; PO save (`POST /api/supply/po/:po`) and shipment save now **return the
  recomputed row(s)** so a cell edit repaints without re-pulling all ~1400 POs. `patch()` gained an optional
  `extraFn` (backward-compatible). Portal `bootstrap` now returns `docsByPo`.
- **`supply/inject.html`** — SUPPLY + PRODUCT admin UI: PRODUCT module, samples overhaul (tabbed, status model,
  approval), PO ▸ Payments additional-costs (read-only + edit link) & deposit analysis, branch delivery notes,
  labels (air-freight, ships-with gating, consolidated crossdock PDF), recent-changes drawer, order-plan
  exception counters, document-approval review.
- **`supply/portal-view.js`** / **`supply/portal.html`** — supplier portal: merged Order Plan + Invoice (2-step),
  DtC re-approval highlighting, confirm/re-confirm boxes, forwarder details, additional costs, sample confirm
  workflow, **document "submit for approval"**, product tab.
- **`artifact_v16.7.html`** — DEMAND/buy planner: buy-plan tweaks (FBA shortfall in whole cartons, inbound
  tooltip), key-account forecast inline editor, misc. *(Data still injected server-side — see §2 of the v26.001
  doc; unchanged here.)*
